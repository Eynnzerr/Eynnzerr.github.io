# Rhythm-game music sources

| Recording | File | Style |
| --- | --- | --- |
| Original Melodic Bass / Sketch 02 | `eynnzerr-melodic-bass-v2.mp3` | Melodic Bass |
| Slipstream | `eynnzerr-drum-and-bass.mp3` | Drum & Bass |
| Prism | `eynnzerr-future-bass.mp3` | Future Bass |
| Halcyon | `eynnzerr-heaven-trap.mp3` | Heaven Trap |

These recordings combine authored musical events, parameter synthesis, and
acoustic one-shots. The scores, melodies, chord voicings, arrangements, bass
lines, and synthesized layers are original to this website.

The single-note piano, acoustic snare, and cymbal in these recordings come from
VSCO 2 Community Edition, released under CC0 1.0 Universal by Versilian Studios.

- Publisher: https://versilian-studios.com/vsco-community/
- Repository and license: https://github.com/sgossner/VSCO-2-CE
- Piano recording: Simon Dalzell / Ivy Audio, redistributed by Versilian Studios.
- Piano mapping: `Keys/Upright Piano/Player_dyn2_rr1_014.wav` = MIDI 49;
  `020.wav` = MIDI 61; `026.wav` = MIDI 73; `032.wav` = MIDI 85.
- Snare: `Percussion/Snare2-HitSN_v9_rr1_Sum.wav`.
- Cymbal: `Percussion/cymbal-crash1_ff_rr1.wav`.

LICENSE.txt, PIANO-INFO.txt, and PIANO-MAPPING.txt preserve the upstream text.
The renderer and reproduction instructions for Slipstream, Prism, and Halcyon
are in `site/scripts/music/` in the site repository. The same authored events
generate each recording and its easy/challenge charts.
